# Create the Public Demo Link for Submission

I cannot create the public link from inside this coding environment because GitHub Pages must be enabled from your GitHub account. The repo now includes a standalone static demo in `docs/` that works without the backend, which is perfect for a quick hackathon link.

## Steps

1. Push this repo to GitHub.
2. Open your repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: your current branch
   - Folder: `/docs`
5. Click **Save**.
6. Wait about 1–3 minutes.
7. Your public demo link will be:

```text
https://YOUR-GITHUB-USERNAME.github.io/CRICKET-LAD/
```

Replace `YOUR-GITHUB-USERNAME` with your GitHub username.

## What to Paste in the Competition

Paste your GitHub Pages URL, for example:

```text
https://YOUR-GITHUB-USERNAME.github.io/CRICKET-LAD/
```

Also paste the project description from `HACKATHON_SUBMISSION.md`.
